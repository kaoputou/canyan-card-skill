# 创建名片引导流程

仅当 `get_my_card` 返回 `status=none` 或错误码 40302（自己无名片）时读取本文件。

---

## 默认策略：一次性收集

默认引导用户**一次性提供所有信息**，收齐后汇总确认再提交。同时告知也可前往窄门餐眼 App「名片」入口自行填写。

告知用户需要提前准备：
- 姓名、手机号、微信号（选填）、职位、企业简称
- 餐饮行业身份（品牌方 / 加盟商 / 供应商 / 服务商）
- 头像图片（直接发送图片文件，不支持外链）
- 个人简介（100 字以内）
- 在职证明图片（企业微信 / 飞书 / 钉钉截图，或工牌等任一即可）
- 是否公开展示名片（默认公开）
- 查看联系方式的条件（选填，如"仅互换后可见"等）

仅当用户信息明显不全时，才按下方逐步收集流程进行。

---

## 逐步收集流程

用户信息明显不全时，按以下顺序逐步收集，已知的跳过：

1. **姓名** — "请问您的姓名？"
2. **手机号** — "您的联系手机号？"
3. **微信号**（选填）— "微信号方便留一下吗？不想填可以跳过。"
4. **职位** — "您目前的职位是？"
5. **企业简称** — "您公司的企业简称？"
6. **身份类型** — "请问您在餐饮行业的身份是：品牌方（自有门店）、加盟商、供应商，还是服务商（媒体/商圈等）？"
7. **企业匹配** — 收到企业简称和身份类型后，调用 `search_target(search=<企业简称>, target_type=<对应类型>)` 搜索已收录企业：
   - **找到候选项**：向用户展示结果，请用户确认选择，记录 `target_slug`，继续下一步。
   - **未找到**：告知用户"暂未找到该企业，请联系窄门餐眼客服微信 **canyan616** 处理"，流程终止。
8. **头像** — "请直接发送一张头像图片，我会帮您上传。"
9. **个人简介** — "简单介绍一下自己，方便别人了解您的背景和合作方向（100 字以内即可）。"
10. **在职证明**（必填其一）— "为核实您的在职身份，请直接发送以下任一图片：企业微信截图、飞书截图、钉钉截图，或其他能证明您在该公司任职的图片（如工牌）。选择您最方便提供的一种即可，我会帮您上传。"
    对应字段：`work_wechat_images` / `feishu_images` / `dingding_images` / `other_images`
11. **是否公开展示**（`show_status`）— "您的名片是否公开展示，让其他人可以搜索到您？（默认公开，回复"是"或"否"即可）"
12. **查看条件**（`view_condition`）— "平台默认需要您同意对方的交换申请后，对方才能获取您的联系方式。如有其他查看条件要求，请告知（否则按默认规则）。"

收集完毕后，向用户展示汇总信息并请求确认，再调用 `create_card`。

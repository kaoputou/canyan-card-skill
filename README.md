# 窄门餐眼·名片 Skill


## 关于窄门餐眼

窄门餐眼是垂直于餐饮行业的大数据平台，覆盖 3400 万+ 门店数据、9000+ 供应链资源、300+ 省市区域，为餐饮经营者、创业者和供应链商家提供品牌查询、科学选址、精准拓客、人脉拓展等一站式决策服务。

## 关于名片系统

窄门餐眼为餐饮行业从业者提供专属的行业名片系统。用户可以在平台上创建实名认证的职业名片，展示姓名、职位、公司和联系方式，并通过名片交换与同行建立连接，快速拓展餐饮行业人脉。

## 这个 Skill 能做什么

安装后，你可以直接用对话的方式操作名片系统，不用打开 App：

- **查看我的名片** — 随时查看自己的名片内容和审核状态
- **创建 / 编辑名片** — 提交名片信息，审核通过后对外展示
- **搜索同行** — 按姓名、公司、职位搜索已认证的餐饮行业名片
- **发起名片交换** — 向感兴趣的同行发送交换请求，建立联系
- **管理往来请求** — 查看收到的请求，接受或拒绝；跟进自己发出的请求状态

## 准备工作

使用前需要满足以下条件：

1. **拥有窄门餐眼账号** — 尚未注册请先下载窄门餐眼 App 完成注册
2. **生成 Skill Token** — 用于授权 AI 智能体代你操作，步骤见下方

## 安装步骤

### 第一步：生成 Skill Token

1. 打开窄门餐眼 App，登录账号
2. 进入「设置 → 连接 AI 智能体」
3. 点击「生成 Skill Token」
4. 复制返回的 Token（形如 `sk_xxxxxx`）——**明文只显示一次，请立即保存**

> Token 随时可在 App 内撤销，撤销后所有 Skill 操作立即失效，重新生成即可恢复。

### 第二步：安装到 AI 智能体

将以下提示词复制给你的 AI 智能体（Claude Code、Codex、Cursor、Windsurf、GitHub Copilot、OpenClaw（小龙虾）、Trae 等），它会自动完成安装：

```
请帮我安装窄门餐眼名片 Skill。

仓库文档：https://github.com/kaoputou/canyan-card-skill
```

安装完成后，将你在第一步获取的 Token 发给 AI 智能体：

```
我的窄门餐眼 Skill Token 是：sk_xxxxxx，请记住它，以后调用名片接口时使用。
```

> 将 `sk_xxxxxx` 替换为你的真实 Token。

## 身份说明

创建名片时需要选择身份，身份决定了配额和展示方式：

| 身份 | 适用场景 |
|------|---------|
| 品牌方 | 公司拥有一家及以上餐饮门店 |
| 加盟商 | 加盟了至少一家餐饮品牌 |
| 供应商 | 为餐饮门店提供食材、耗材、器具或服务 |
| 其他 | 媒体、商圈招商等 |
